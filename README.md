# ChromaLab

Zero-dependency WCAG 2.1 color scale and design token foundry.

## Features
- **50–950 Algorithmic Ramp**: Derives 11 balanced color tokens from any hex or HSL input with one-click clipboard copy.
- **WCAG Contrast Pair Inspector & Matrix**: Real-time relative luminance ratio checks (`AA Normal`, `AA Large`, `AAA Normal`), swap FG/BG, and one-click `Auto-Fix to AA`.
- **Color-Vision Deficiency Simulation**: Live inline SVG `<feColorMatrix>` filters for `Protanopia`, `Deuteranopia`, `Tritanopia`, and `Achromatopsia`.
- **Live Component & Token Export**: Inspect live CSS token styling on buttons/badges/cards and export as CSS Variables, Tailwind `@theme`, or W3C JSON tokens.
